## 2. What changed from the previous version

- **Design.** The navy/gold editorial design is gone. New system: canvas #F7F9FC, ink #17233B, primary #4169E1, subject accents (math #6654E8, physics #0E9F9A, chemistry #F08B43), success #20A477; Bricolage Grotesque headings with Figtree body text; white cards, rounded components, restrained shadows; dark mode. One component library (`src/components/ui`) is used by every page.
- **Homepage.** Live tabbed demo (projectile, parabola, ideal gas), subject sections with real pathway data, the four lesson modes, featured lessons, a simulation showcase, a math pathway preview, student benefits and live curriculum counts.
- **Lessons.** Learn, Experiment (simulations) and Practice (checked questions with hints and solutions) tabs; objectives; progress, bookmarks; private feedback on the lesson or any activity; moderated discussion.
- **Backend.** Accounts, RBAC, student records, practice, community, support and the admin API, all in the existing Worker/Pages Functions app on D1.
- **Authentication choice changed** from the earlier plan (Better Auth) to a small in-house implementation on Web Crypto: the free Workers plan allows about 10 ms of CPU per request, and Better Auth's scrypt hashing would exceed it. Passwords use PBKDF2-SHA256 at 100,000 iterations (the Workers maximum) with per-user salts; parameters are stored per user so they can be raised later. Session and reset tokens are 256-bit random values stored only as SHA-256 hashes; reset tokens expire in an hour and are single-use; a reset signs out every session.

- **Session 18 (mobile pass and homepage).**
  - Phone header: one-line logo, 44 px buttons, sign-in and theme moved into the menu.
  - Lesson tabs fit four across at 360 px.
  - Sims keep their picture pinned while the controls scroll, with bigger slider thumbs on touch screens.
  - The Labs page scrolls to the chosen sim on phones.
  - The animation library was removed, shrinking the main bundle from 139 kB to 92 kB gzipped.
  - The "N lessons ready" badges and progress bars are gone now that every course is complete; signed-in students see their own progress instead.
  - The homepage shows six example simulations with a link to the Labs page, which lists all 77.

- **Session 19.** Admin and account pages checked at 360 px while signed in as an owner. The pages fixed:
  - users, analytics and formulas (tables)
  - ticket and lesson studio (grids)
  - the admin layout (side menu)

  The phone header hides the wordmark when signed in.

## 3. Production safety

- Production is untouched: same code, same database, same 1 lesson. Staging has a separate D1 database (`eureka-db-staging`).
- Migrations 0004–0006 are additive (no table is dropped or rewritten; a test enforces no `DROP TABLE`/`DELETE FROM` after 0001). Content migrations use `INSERT OR IGNORE` and are idempotent (tested), so they never overwrite admin edits.
- The original lesson keeps its id and content; it gains objectives, an interactive balance, a walkthrough and practice.
- `scripts/deploy.sh production` exports a backup before migrating.
